# FinPlanner v0.9.0-beta.1

The first public beta. FinPlanner is a fully local, offline-first retirement
planner: your numbers never leave this device — there is no account, no
telemetry, and a CI egress test proves the running app makes zero network
requests. Apache-2.0 licensed, no warranty.

## What's in the beta

- **Deterministic projection** — contributions, employer match, spending
  profiles (with essential-spending floor), one-off spends (repeating +
  inflation), liabilities, income streams incl. Social Security claiming-age
  shifts, and an unmet-spending runout year. Real (today's) dollars.
- **Monte Carlo risk view** — deterministic-seed engine (any laptop replays
  the identical numbers), success probability, worst-percentile outcomes,
  goal attainment, sequence-of-returns risk, drawdown context, stress windows
  and presets.
- **Mitigation comparison** — guardrail withdrawal and cash-buffer policies
  measured against the same plan, side by side (§C.3). Both default OFF;
  turning them on never silently changes an existing plan's headline numbers.
- **Plan snapshots & diff** — freeze a plan's exact parameter set, change
  something, snapshot again, and see every changed parameter plus the
  terminal-wealth delta. Comparisons always read the stored snapshot, never
  live data.
- **Backup / restore** — single encrypted file containing the whole local
  database (round-trip tested in CI), plus CSV/plan import with a parse-once
  review step.
- **Terms of Use clickwrap** — first-run agreement with locally recorded
  acceptance (versioned, re-prompted on term changes), plus persistent
  "projections, not advice" notices everywhere results appear.

## Known limitations (beta)

- Market return/volatility defaults are **unvalidated placeholders**, clearly
  labeled in-app, pending a sourced 1970–2024 assumption set. Treat every
  projection as conditional on those inputs.
- No tax modeling yet (tax-advantaged accounts are modeled as wrappers
  only). Social Security and tax-related figures are simplified estimates of
  complex, changing law — verify against IRS/SSA publications and a qualified
  professional.
- The Terms are owner-approved and conspicuously labeled **not reviewed by an
  attorney**; that label appears at the agreement screen and in the full text.
- The engine benchmark gate currently runs on desktop-class CI hardware;
  low-end phone validation is still outstanding.

## How to run

Download `finplanner-v0.9.0-beta.1-static.zip`, unzip, and serve the folder
with any static file server (`npx serve .`, `python3 -m http.server`) on
`localhost` or HTTPS — service workers require a secure context. No build
step, no Node needed at runtime. Or from source: `pnpm install && pnpm
build`, same serve step. Latest Chrome or Firefox; needs IndexedDB + OPFS
(any current desktop/mobile browser).
